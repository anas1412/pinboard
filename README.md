# Pinboard releases

Installers for [Pinboard](https://anas1412.github.io/pinboard-releases/), a Kanban board for
your coding agents: every ticket is a Claude Code or OpenCode session, tracked live.

**Download:** [latest release](https://github.com/anas1412/pinboard-releases/releases/latest)
(Linux AppImage, .deb, .rpm; Windows setup .exe, .msi).

**Install guide:** https://anas1412.github.io/pinboard-releases/guide/install

This repository only holds the installers and the website. Report problems in
[Issues](https://github.com/anas1412/pinboard-releases/issues).
